# Explaining and removing service freezes

Use **Client Profile → Access & next steps** from Students, Support, or LexAI. Check the client ID before requesting an access change.

- **Account sign-in** describes whether the student can log in. A LexAI or recommendation freeze does not itself stop course learning.
- **Available now** describes usable service access. A valid subscription record alone does not mean the service is available.
- **Manually frozen** and **Awaiting activation** can apply together. Removing the freeze leaves pending activation in place.
- **Automatic activation deadline** is separate from a scheduled unfreeze. Under current policy, activation can occur at the deadline with incomplete requirements, while a manual freeze remains.
- **Allowed when service is active** is notification permission. It does not activate or unfreeze recommendations.

Ask an admin or authorized subscription manager to unfreeze the named service using its existing **Unfreeze** control in recommendation management or the Comprehensive Package Holders list. The shared profile's **Copy handoff** button prepares a request; it does not send it or change access. Refresh the profile afterward and confirm the remaining activation state. Do not use broker or course skip just to remove a freeze.
